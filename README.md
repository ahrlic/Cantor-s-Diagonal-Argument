# Cantor-s-Diagonal-Argument
Cantor's Diagonal Argument States that real numbers cannot be counted by natural numbers

The argument created from the inital list of numbers, cannot equal any number in the list. You can continue to build numbers, the list will never complete. 
Therefore no compelete list can exist, making it so the real numbers are uncountable.
